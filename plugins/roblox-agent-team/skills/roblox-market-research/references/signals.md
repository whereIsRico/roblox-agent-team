# Signals checklist (scouts)

For each game you look at, collect what you can. Mark every number
**measured** (seen on a page) or **estimated** (with how).

## Demand
- CCU now, and history (7d / 30d) if a tracker shows it
- Total visits, created date, last update date
- Like ratio, favorites per 1k visits (Rotrends shows this)

## What players actually want (look at real players, not blogs)
- Top YouTube/TikTok videos about it in the last month: titles, view counts,
  what moment the thumbnails/clips show. That's the hook players share.
- Reddit (r/roblox, the game's own subreddit if any), DevForum: what do
  players praise, what do they complain about, what do they ask for?
- Update log / description: what the dev adds that brings CCU back up?
- Count how many players in a lobby are doing the same thing: that's the
  core loop.

## Mechanics
- The core loop in one sentence (what you repeat every 30 seconds)
- The session loop (why you stay 20+ minutes)
- The return loop (why you come back tomorrow: daily rewards, timers,
  rebirths, collections, friends, events)
- Social hooks: trading, stealing, co-op, competition, showing off
- What a new player does in the first 60 seconds

## Thumbnails
Save each game's current thumbnails (from the game page or Roblox's
thumbnails API) into the thumbs folder, then look at them:
- What's shown: character + reaction, the core action, the reward, the world?
- Text: none / 1-3 words / more. Readable at phone size?
- Colours and contrast, how cluttered
- Does it match what you'd actually do in the first 3 minutes? Mismatch =
  quick exits = buried by the algorithm
- Pattern across the top 3 vs the failed copies: what do winners do that
  losers don't?

## Monetization
- Game passes and dev products: names and Robux prices
- What's sold: speed/boost, luck, cosmetics, VIP, skips, revives
- Anything pay-to-win that players complain about

## Why the dead copies died
- Same loop, so what's different: thumbnail, first minute, polish, no
  return loop, no updates, launched too late?
