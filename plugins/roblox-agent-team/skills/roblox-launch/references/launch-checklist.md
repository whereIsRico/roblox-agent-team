# Launch checklist

Re-check every requirement against official docs before relying on it. As
written (Nov 2026):

## Store assets
- [ ] Icon: 512x512 PNG/JPG
- [ ] Thumbnails: 1920x1080 (16:9), up to 10; 2-5 active for personalization
- [ ] Name, description, genre, devices, max players

## Publishing (user)
- [ ] File > Publish, metadata saved
- [ ] Content Maturity questionnaire
- [ ] Account in good standing, at least a couple of days old
- [ ] Age check (facial estimation or government ID)

## All-ages release (user) - needed to reach most of Roblox's players
- [ ] ID verification
- [ ] 2-step verification
- [ ] Roblox Plus/Premium for 2 consecutive months, OR a refundable
      publishing fee (official docs list 1,000 Robux; an optional paid
      expedited review also exists - check the current amount)
- [ ] Pass the evaluation (one Sept 2026 guide describes roughly 250
      qualifying plays from engaged, age-checked 16+ players within 60 days;
      check Creator Hub > Eligibility for the real current threshold)
- [ ] Maturity rating of Minimal, Mild or Moderate

## Money
- [ ] Passes and products created, wired, tested (including leave mid-purchase)
- [ ] ProcessReceipt idempotent
- [ ] DevEx: 13+, verified email, tax form (W-8 outside the US), 30,000
      Earned Robux minimum, once a month

## Analytics
- [ ] Onboarding funnel, economy events, core-loop custom events
- [ ] Share links created for every promo channel
